# FaqBundle for OroCommerce

A lightweight and flexible FAQ management bundle for Orocommerce.

## Overview

FAQBundle provides a simple way to manage Frequently Asked Questions within OroCommerce. It is designed to be minimal, reusable, and easy to integrate into existing storefronts and CMS content.

The bundle introduces two main concepts:
 - Items (questions & answers)
 - Categories (to organize items)

## Features

- Manage FAQ items with localized questions and answers
- Organize items into categories
- Simple and intuitive admin interface
- Display a full FAQ page (/faq)
- Integrate the FAQ page into the Web Catalog
- Reuse FAQ content anywhere using a Content Widget in the WYSIWYG editor
